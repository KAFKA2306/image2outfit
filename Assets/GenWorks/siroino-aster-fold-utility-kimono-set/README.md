# Aster Fold Utility Kimono Set

Canonical product workspace for `siroino-aster-fold-utility-kimono-set` from Issue #596.

The accepted construction is a cropped modern wrap-kimono jacket, fitted camisole, asymmetric wrap skort, bounded obi and two real interlocking Aster Fold clasp plates with facings. The product deliberately excludes hood, cape, harness web, long free straps and physics-dependent tails.

Blender/FBX/render evidence is produced by the canonical product build and pose-render paths. The ProductManifest remains WORKING until direct visual review and available Unity/NDMF/VRChat evidence are recorded.
