# Siroino Wide Cargo

参考画像を完全複製せず、VRChatでの輪郭、金属ハイライト、非対称ディテール、ポーズ時の読みやすさを優先したワイドカーゴ衣装です。

## 対象

- Avatar: SiroinoSotai v1.0
- Unity: 2022.3.22f1
- Setup: Modular Avatar
- Status: `SPECIFIED`

## 意匠

- 超ワイドな黒カーゴシルエット
- 腰のカットアウトと左右非対称ベルト
- 長いセンタージップ
- 膝開口、ストラップ、金属パーツ
- 黒つぶれを避けた布・ベルト・金属の材質分離

## 完了条件

`Prefabs/Outfit/`の衣装単体Prefabと、`Prefabs/Integrated/SiroinoSotai/`の着せ替え確認Prefabを作成します。立位、腕上げ、腕組み、しゃがみ、座り、伏せ、歩行相当のウェイト・貫通検証、SDK Build & Test、VRChat内レビューが完了するまでは販売可能と判定しません。

Unityでは `GenWorks > Product Catalog` から本製品を選択し、Prefab、統合確認Prefab、プレビュー、文書へ直接移動できます。
