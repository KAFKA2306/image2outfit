# Siroino Wide Cargo

Original, logo-free wide cargo outfit for SiroinoSotai v1.0. The design includes separated wide legs, knee openings, flat belts, asymmetric hardware, cargo pockets, and a long front zipper.

## Unity setup

The outfit prefab is `Assets/GenWorks/siroino-wide-cargo/Prefab/SiroinoWideCargo.prefab`. The integrated prefab is `Assets/GenWorks/siroino-wide-cargo/Prefab/SiroinoSotai_WideCargo.prefab`. Use the outfit prefab under the compatible avatar root for the Modular Avatar / NDMF integration workflow. These paths are recorded in `ProductManifest.json`.
