# HAOLAN Cow Hood Knit Set v1.0

Generated garment candidate for HAOLAN. This directory does not contain the licensed HAOLAN avatar source.

## Files

- `HAOLAN_CowHoodKnitSet.fbx`: skinned garment FBX with HAOLAN-compatible armature names
- `HAOLAN_CowHoodKnitSet.prefab`: Unity prefab wrapper
- `Textures/`: cow-knit, normal, roughness, black-knit, fuzzy, and sheer textures
- `HAOLAN_CowHoodKnitSet_preview.webp`: four-view render of the actual generated mesh on the supplied HAOLAN source
- `HAOLAN_CowHoodKnitSet_preview.glb`: independent static inspection model
- `audit.json` / `AUDIT_REPORT.md`: release-gate evidence

## Status

**NO-GO for customer release.** Static visual quality is reviewable, but Unity import, animated clipping, VRChat Build & Test, and in-headset material review are not yet complete.
