# HAOLAN Cow Hood Knit Set v1.0

Generated garment candidate for HAOLAN. This directory does not contain the licensed HAOLAN avatar source.

## Files

- `HAOLAN_CowHoodKnitSet.fbx`: skinned garment FBX with HAOLAN-compatible armature names
- `HAOLAN_CowHoodKnitSet.prefab`: Unity prefab wrapper
- `Textures/`: cow-knit, normal, roughness, black-knit, fuzzy, and sheer textures
- `HAOLAN_CowHoodKnitSet_preview.webp`: four-view render of the generated candidate
- `HAOLAN_CowHoodKnitSet_preview.glb`: independent static inspection model
- `audit.json` / `AUDIT_REPORT.md`: structural and release-gate evidence
- `VISUAL_REVIEW.md`: strict manual appearance audit
- `HAOLAN_CowHoodKnitSet_v1.zip`: packaged candidate

## Status

**NO-GO for customer release.** The strict manual review classifies the current appearance as blockout/prototype quality, not a sellable HAOLAN garment. Unity import, animated clipping, VRChat Build & Test, and in-headset material review also remain incomplete.
